LOVE YOU — versão web para celular

COMO TESTAR:
1. Extraia a pasta LoveYouWeb.
2. Abra index.html no navegador para testar no computador.

COMO PUBLICAR GRÁTIS COM GITHUB PAGES:
1. Entre em https://github.com e crie um repositório público (por exemplo: love-you-agatha).
2. Envie o arquivo index.html para a raiz do repositório.
3. Abra Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Escolha Branch: main e Folder: /(root), depois Save.
6. Aguarde alguns minutos. O GitHub mostrará o endereço do site nessa mesma página.
7. Envie o link pelo WhatsApp.

Este é um port para navegador inspirado no algoritmo do love.py. Como turtle/Tkinter não rodam diretamente no navegador do celular, a animação foi reimplementada em Canvas/JavaScript.
